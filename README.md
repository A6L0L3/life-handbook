## README · 导览

### README_1 这是什么，与库内体例

本仓库收录五部经典实用手册的笔记化重构，按需求场景组织。各文档以「单篇知识库」为通例组织，库内体例为：

```
# 篇名 · 一句话定位
## README · 导览
### README_1 子板块名称
### README_2 子板块名称
## 板块0 · 学习路径和建议
### 0_1 学习路径
### 0_2 使用建议与边界声明
## 板块1 · 板块一的名称
### 1_1 板块1子板块名称
```

- 每篇一级标题只有 1 个（篇名），其下以 `## README · 导览`（`### README_N`）开头，接 `## 板块0 · 学习路径和建议`（`### 0_1 学习路径`、`### 0_2 使用建议与边界声明`）→ `## 板块1…N` 主题；小节编号形如 `0_1`、`12_3`，可按主题独立查阅。
- 各篇普遍遵循同一写法：先给学习路径与认知定位，再讲原理与操作流程，最后落到底层公理、避坑清单、速查附录与验证方法。

## 板块0 · 学习路径和建议

### 0_1 学习路径

1. **按需取用，不从头读到尾**：生活琐事翻《万事不求人》，技能学习翻《军地两用人才之友》，应急安全翻《民兵军事训练手册》，健康处置翻《赤脚医生手册》，农事经营翻《齐民要术》。
2. **先读对应手册板块0**：明确该手册的认知定位、操作前提与验证标准。
3. **照流程做 + 用验证标准自查**：每篇把内容改造成可演练流程与可检验真伪的标准，读后照做一遍。
4. **建立家庭常备索引**：建议把五本手册的速查索引集中归档，遇事按场景直查。

### 0_2 使用建议与边界声明

- 本仓库收录生活技能、健康与农业等实用内容，仅作为常识性参考；涉及医疗、用药、安全操作等请务必咨询持证专业人员，本仓库**不构成诊疗或作业指导建议**。
