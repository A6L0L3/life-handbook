## 库内体例

各文档以「单篇知识库」为通例组织：

1. `XX.md`——合订 / 单篇知识库，一篇读完全体系（本库 5 篇，各自独立成册）；
2. 每篇一级标题只有 1 个（篇名），其下以 `## README · 导览`（其下 `### README_N`）开头，接 `## 板块0 · 学习路径建议`（其下 `### 0_1 学习路径`、`### 0_2 使用建议与边界声明`）→ `## 板块1…N` 主题；小节编号形如 `0_1`、`12_3`，可按主题独立查阅；
3. `读书笔记/`（本库如有）——所据原著的逐本读书笔记。

各篇普遍遵循同一写法：先给学习路径与认知定位，再讲原理与操作流程，最后落到底层公理、避坑清单、速查附录与验证方法。所据原书（PDF/EPUB 等）不在本仓库内，本仓库仅收录整理笔记与知识库。
